# IPO Automation Django App

**IPO Automation** is a web-based application built with **Django** that automates the process of tracking and managing IPO (Initial Public Offering) data. It allows users to monitor IPO schedules, manage applications, and analyze IPO-related information efficiently.

---

## Features

- View upcoming IPOs and their details.
- Automate data collection and tracking of IPO submissions.
- Simple and intuitive interface for managing IPO-related information.
- Easily deployable using Docker for consistent development and production environments.

---

## Technology Stack

- **Backend:** Django (Python)
- **Frontend:** Django templates / HTML / CSS / JS
- **Database:** SQLite (default, can be extended to PostgreSQL or MySQL)
- **Containerization:** Docker and Docker Compose
